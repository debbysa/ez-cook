# 🍳 Ez Cook

**Ez Cook** is an intelligent web application designed to classify Indonesian cuisine types based on provided ingredients. It also recommends similar recipes using the same or related ingredients, making it easier for users to discover and cook familiar dishes.

## Features

- **Cuisine Classification:**  
   Input a list of ingredients, and Ez Cook predicts the type of Indonesian cuisine they belong to.

- **Recipe Recommendations:**  
   Get suggestions for similar recipes using your chosen ingredients, helping you explore new dishes or variations.

- **Localized Dataset:**  
   Built exclusively with Indonesian food data, ensuring recommendations are relevant and familiar to users in Indonesia.

## Technology Stack

- **Python:** Core backend logic and data processing.
- **Streamlit:** Interactive and user-friendly web interface.
- **OpenRouter Model:** Powers the cuisine classification and recipe recommendation engine.

## Use Cases

- Discover what Indonesian dish you can make with ingredients you have.
- Explore new recipes similar to your favorite dishes.
- Learn more about Indonesian cuisine and its diversity.

## Getting Started

1. Enter your available ingredients.
2. Let Ez Cook classify the cuisine and suggest recipes.
3. Enjoy cooking and experimenting with Indonesian food!
